2. CodeWalker - Copyright (c) 2017-2019 dexyfex
-----------------------------------------------
https://github.com/dexyfex/CodeWalker
Reference for the RPF7 archive format and for converting archives to the OPEN format. Official
Modexa builds embed CodeWalker's encrypted key bundle (magic.dat). The bundle is encrypted with
the game's own key and can only be opened with an installed copy of GTA V.


3. CodeWalkerProjects - crxhvrd
-------------------------------
https://github.com/crxhvrd/CodeWalkerProjects
Its standalone OIV installer / uninstaller guided Modexa's OIV support (mods-folder handling,
the .oivs format, reversing XML and text edits on uninstall). No source code is copied from it.


4. OpenIV team - OpenIV.asi and its ASI loader
----------------------------------------------
https://openiv.com
Official Modexa builds install OpenIV.asi (+ ASI loader) into GTA V Legacy so the game reads the
"mods" folder. The OIV package format (assembly.xml, package version 2.x) is defined by OpenIV.

-----------------------------------------------------------------

Used to read the RAR / ZIP / 7z prerequisite packs.
